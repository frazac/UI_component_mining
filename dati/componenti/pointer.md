## it
# Puntatore
Il cursore, o puntatore, è un elemento grafico che riproduce la posizione e il movimento di un dispositivo di puntamento. Il cursore può cambiare aspetto o stato di interazione a seconda del contesto e della posizione. Il più notevole è il cursore di attesa ([throbber](https://en.wikipedia.org/wiki/Throbber)), raffigurato in Apple macOS come una rotella colorata che gira e nelle vecchie versioni di Microsoft Windows come una clessidra (oggi un cerchio che gira).

## en
# Pointer
The cursor or pointer is a graphical element that mirrors the position and movement of a pointing device. The cursor can change appearance or interaction state depending on context and position. The most remarkable is the wait cursor ([throbber](https://en.wikipedia.org/wiki/Throbber)), depicted in Apple macOS as a spinning colour wheel and in older versions of Microsoft Windows as an hourglass (today a spinning circle).

## fr
# Pointeur
Le curseur, ou pointeur, est un élément graphique qui reproduit la position et le mouvement d'un dispositif de pointage. Le curseur peut changer d'apparence ou d'état d'interaction selon le contexte et la position. Le plus remarquable est le curseur d'attente ([throbber](https://en.wikipedia.org/wiki/Throbber)), représenté dans Apple macOS par une roue colorée qui tourne et, dans les anciennes versions de Microsoft Windows, par un sablier (aujourd’hui un cercle qui tourne).

## zh
# 指针
光标或指针是一种图形元素，反映定点设备的位置和移动。光标可以根据情境和位置改变外观或交互状态。最引人注目的是等待光标（[throbber](https://en.wikipedia.org/wiki/Throbber)），在 Apple macOS 中表现为旋转的彩色圆盘，在旧版 Microsoft Windows 中表现为沙漏（如今为旋转的圆圈）。
