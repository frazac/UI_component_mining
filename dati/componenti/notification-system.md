## it
# Sistema di notifiche
L'insieme dei messaggi con cui un'app o un sistema operativo informa gli utenti degli eventi: notifiche push, banner, badge e un centro notifiche che le raccoglie. Gli utenti devono poter scegliere quali notifiche ricevere.

## en
# Notification system
The set of messages through which an app or operating system tells users about events: push notifications, banners, badges and a notification center that collects them. Users should be able to control which notifications they receive.

## fr
# Système de notifications
L'ensemble des messages par lesquels une application ou un système d'exploitation informe les utilisateurs des événements : notifications push, bannières, badges et un centre de notifications qui les regroupe. Les utilisateurs doivent pouvoir choisir les notifications qu'ils reçoivent.

## zh
# 通知系统
应用或操作系统向用户告知事件的一整套消息：推送通知（push）、横幅、徽标（badge），以及汇集这些消息的通知中心。用户应能自行选择接收哪些通知。
