## it
# Sistema di versionamento (per esempio Git)
Un sistema che registra le versioni successive dei file, così che le modifiche si possano confrontare, ripristinare e unire. Nello sviluppo software il più diffuso è Git; anche gli strumenti di design offrono cronologie delle versioni simili.

## en
# Versioning system (e.g., Git)
A system that records successive versions of files, so that changes can be compared, restored and merged. Git is the most widely used one in software development; design tools offer similar version histories.

## fr
# Système de gestion de versions (par exemple Git)
Un système qui enregistre les versions successives des fichiers, afin de pouvoir comparer, restaurer et fusionner les modifications. Git est le plus utilisé dans le développement logiciel ; les outils de design proposent des historiques de versions similaires.

## zh
# 版本控制系统（例如 Git）
记录文件各个版本的系统，便于比较、恢复和合并修改。Git 是软件开发中使用最广泛的版本控制系统；设计工具也提供类似的版本历史。
