## it
# Pulsante di chiusura di macOS (il punto nel pulsante rosso)
Il punto dentro il pulsante rosso di chiusura segnala modifiche non salvate.

## en
# macOS close button (the dot in the red button)
The dot inside the red close button signals unsaved changes.

## fr
# Bouton de fermeture de macOS (le point dans le bouton rouge)
Le point à l'intérieur du bouton rouge de fermeture signale des modifications non enregistrées.

## zh
# macOS 关闭按钮（红色按钮中的圆点）
