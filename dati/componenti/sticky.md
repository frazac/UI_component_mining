## it
# Box, barra o menu sticky («affix»)
Un box, una barra o un menu che scorre con la pagina finché raggiunge una posizione stabilita, poi resta fermo lì (per esempio un header agganciato in cima alla finestra). Bootstrap 3 chiamava questo comportamento «affix»; oggi si ottiene con la proprietà CSS position: sticky.

## en
# Sticky box, bar or menu ("affix")
A box, bar or menu that scrolls with the page until it reaches a set position, then stays fixed there (for example a header pinned to the top of the viewport). Bootstrap 3 called this behaviour "affix"; today it is done with the CSS property position: sticky.

## fr
# Boîte, barre ou menu collant (sticky, « affix »)
Une boîte, une barre ou un menu qui défile avec la page jusqu'à atteindre une position donnée, puis reste fixé à cet endroit (par exemple un en-tête épinglé en haut de la fenêtre). Bootstrap 3 appelait ce comportement « affix » ; aujourd'hui on l'obtient avec la propriété CSS position: sticky.

## zh
# 吸附（sticky）框、栏或菜单（“affix”）
随页面滚动、到达设定位置后便固定不动的框、栏或菜单（例如固定在视口顶部的页眉）。Bootstrap 3 将这种行为称为“affix”；如今用 CSS 属性 position: sticky 实现。
