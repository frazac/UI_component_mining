## it
# Palette dei comandi
Un elenco di comandi con ricerca, che si apre con una scorciatoia da tastiera (per esempio in Visual Studio Code) e in cui si digita per trovare ed eseguire un’azione.

## en
# Command palette
A searchable list of commands opened with a keyboard shortcut (for example in Visual Studio Code), where users type to find and run an action.

## fr
# Palette de commandes
Une liste de commandes avec recherche, ouverte par un raccourci clavier (par exemple dans Visual Studio Code), dans laquelle on tape pour trouver et exécuter une action.

## zh
# 命令面板
通过键盘快捷键打开、可搜索的命令列表（例如 Visual Studio Code 中的命令面板），用户输入文字即可查找并执行操作。
