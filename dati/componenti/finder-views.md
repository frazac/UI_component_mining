## it
# Viste del Finder di macOS (con anteprima)
Il Finder di macOS può mostrare il contenuto di una cartella in viste diverse: icone, elenco, colonne e galleria. L'anteprima mostra un'immagine più grande e le informazioni sul file selezionato senza aprirlo.

## en
# macOS Finder views (with preview)
The macOS Finder can show the content of a folder in different views: icons, list, columns and gallery. The preview shows a larger image and information about the selected file without opening it.

## fr
# Présentations du Finder de macOS (avec aperçu)
Le Finder de macOS peut afficher le contenu d'un dossier selon différentes présentations : icônes, liste, colonnes et galerie. L'aperçu montre une image plus grande et des informations sur le fichier sélectionné sans l'ouvrir.

## zh
# macOS 访达的显示方式（带预览）
macOS 的访达（Finder）可以用不同的显示方式展示文件夹内容：图标、列表、分栏和画廊。预览会显示所选文件的大图和相关信息，无需打开文件。
