## it
# Pagina 404
La pagina di errore che compare quando l'indirizzo richiesto non esiste (codice di stato HTTP 404). Una buona pagina 404 spiega che cosa è successo e offre una via d'uscita, come un link alla home page o un campo di ricerca.

## en
# 404 page
The error page shown when a requested address does not exist (HTTP status 404). A good one explains what happened and offers a way back, such as a link to the home page or a search field.

## fr
# Page 404
La page d'erreur affichée quand l'adresse demandée n'existe pas (code d'état HTTP 404). Une bonne page 404 explique ce qui s'est passé et propose une issue, comme un lien vers la page d'accueil ou un champ de recherche.

## zh
# 404 页面
当请求的地址不存在时显示的错误页面（HTTP 状态码 404）。好的 404 页面会说明发生了什么，并提供返回的路径，例如指向首页的链接或搜索框。
