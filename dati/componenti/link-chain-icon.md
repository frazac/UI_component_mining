## it
# Icona della catena per i link
Un'icona con due anelli di catena, usata per rappresentare i link: indica i comandi per inserire o copiare un link, o le ancore per condividere una sezione specifica di una pagina.

## en
# Hyperlink chain icon
An icon showing two chain links, used to represent hyperlinks: it marks commands to insert or copy a link, or anchors for sharing a specific section of a page.

## fr
# Icône de chaîne des liens hypertextes
Une icône représentant deux maillons de chaîne, utilisée pour figurer les liens hypertextes : elle signale les commandes pour insérer ou copier un lien, ou les ancres permettant de partager une section précise d'une page.

## zh
# 超链接链条图标
由两个链环组成的图标，用于表示超链接：它标示插入或复制链接的命令，或用于分享页面某一部分的锚点。
