## it
# Picture-in-Picture
Un video continua a essere riprodotto in una piccola finestra mobile sopra altre app o contenuti, così gli utenti possono guardarlo mentre fanno altro. I browser lo mettono a disposizione delle pagine web con la Picture-in-Picture API.

## en
# Picture-in-Picture
A video keeps playing in a small floating window above other apps or content, so users can watch it while doing something else. Browsers make it available to web pages through the Picture-in-Picture API.

## fr
# Picture-in-Picture (image dans l'image)
Une vidéo continue d'être lue dans une petite fenêtre flottante au-dessus d'autres applications ou contenus, pour que les utilisateurs puissent la regarder tout en faisant autre chose. Les navigateurs mettent cette fonction à la disposition des pages web via l'API Picture-in-Picture.

## zh
# 画中画（Picture-in-Picture）
