## it
# Selettore a tendina con filtro
Più componenti combinati: filtro di testo, pulsante ed elenco a tendina. Il dropdown permette di scegliere le opzioni da un menu; il filtro permette di restringere rapidamente le opzioni digitando parole chiave, cosa particolarmente utile con elenchi lunghi. Riduce il carico cognitivo e rende la selezione più efficiente.

## en
# Dropdown selector with filtering
Several components combined: text filter, button and drop-down list. The dropdown lets users select options from a menu; the filter lets them quickly narrow down the options by typing keywords, which is particularly useful with long lists. It reduces cognitive load and improves selection efficiency.

## fr
# Liste déroulante avec filtre
Plusieurs composants combinés : filtre de texte, bouton et liste déroulante. La liste déroulante permet de choisir des options dans un menu ; le filtre permet de réduire rapidement les options en tapant des mots-clés, ce qui est particulièrement utile avec de longues listes. Il réduit la charge cognitive et rend la sélection plus efficace.

## zh
# 带筛选的下拉选择器
多个组件的组合：文本筛选框、按钮和下拉列表。下拉菜单（dropdown）让用户从菜单中选择选项；筛选框让用户通过输入关键词快速缩小选项范围，这在长列表中尤其有用。它能降低认知负荷，提高选择效率。
