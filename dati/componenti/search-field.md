## it
# Campo di ricerca
Un componente combinato, sempre determinato dal funzionamento del back end: la ricerca è una richiesta (query) al database e produce una «vista» di risultati.

## en
# Search field
A combined component, always determined by the operation of the back end: the search is a request (query) to the database and produces a "view" of results.

## fr
# Champ de recherche
Un composant combiné, toujours déterminé par le fonctionnement du back end : la recherche est une requête (query) adressée à la base de données et produit une « vue » de résultats.

## zh
# 搜索框
一种组合组件，始终取决于后端（back end）的运作方式：搜索是向数据库发出的请求（query），并生成一个结果“视图”。
