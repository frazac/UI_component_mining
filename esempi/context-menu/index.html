Clic destro (o pressione prolungata) su un fileRight-click (or long press) a fileClic droit (ou appui long) sur un fichier右键点击（或长按）一个文件

      Da tastiera: seleziona un file con Tab e premi Maiusc+F10; frecce per scorrere, Invio per scegliere, Esc per chiudere.Keyboard: Tab to a file and press Shift+F10; arrows to move, Enter to choose, Esc to close.Au clavier : Tab jusqu’à un fichier puis Maj+F10 ; flèches pour parcourir, Entrée pour choisir, Échap pour fermer.键盘：用 Tab 选中文件后按 Shift+F10；方向键移动，回车选择，Esc 关闭。
