Fai qualcosa, poi annullaDo something, then undoFaites quelque chose, puis annulez先做点什么，再撤销
Cronologia: clicca per tornare a quel puntoHistory: click to go back to that pointHistorique : cliquez pour revenir à ce point历史记录：点击回到那一步

    Annulla torna indietro di un passo, Ripeti lo rifà; un’azione nuova dopo un annullamento cancella i passi barrati. Tastiera: ⌘/Ctrl + Z, ⇧ + ⌘/Ctrl + Z.Undo goes back one step, Redo does it again; a new action after an undo discards the struck-out steps. Keyboard: ⌘/Ctrl + Z, ⇧ + ⌘/Ctrl + Z.Annuler revient d’un pas, Rétablir le refait ; une nouvelle action après une annulation supprime les pas barrés. Clavier : ⌘/Ctrl + Z, ⇧ + ⌘/Ctrl + Z.撤销回退一步，重做再执行一次；撤销后执行新操作会丢弃被划掉的步骤。键盘：⌘/Ctrl + Z，⇧ + ⌘/Ctrl + Z。
